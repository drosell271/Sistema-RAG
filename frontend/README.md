# Frontend (React)

Modern Single Page Application (SPA) for the RAG Platform.

## 🛠 Tech Stack

- **Framework**: React 18+
- **Build Tool**: Vite
- **Styling**: TailwindCSS
- **Icons**: Lucide React

## 🐳 Docker Note

In the "Simplified" Docker setup, this runs as a lightweight Node container executing `vite preview`.
For production, it is recommended to replace this with an Nginx container.

## 🚀 Development

```bash
cd frontend
npm install
npm run dev
```

## Qué guía usar

- Usa `quickstart-local.md` si quieres levantar todo en una sola máquina con `docker compose`.
- Usa `swarm-proxmox-nfs.md` si vas a desplegar en varios nodos con Docker Swarm y una carpeta compartida NFS para uploads.
- Usa `public-repo-checklist.md` antes de abrir el repositorio para revisar nombres internos, credenciales, branding y capturas.
